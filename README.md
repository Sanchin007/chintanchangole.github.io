# Chintan Changole Portfolio v16 — Commerce Operations Lab

Static GitHub Pages portfolio. No backend required.

## Built from v15
v15 already contained the Google-inspired business-process portfolio, CMA CGM e-commerce dashboard, SpotOn / Booking simulations, repeat-booking and quote-expired exception flows, before-vs-after views, architecture, KPIs, presentation mode and deep project case studies.

## What changed in v16
- Added a new company-neutral **Commerce Operations Lab** as a reference simulation.
- Added an interactive **marketplace order exception workflow** from detection to continuous improvement.
- Added a detailed **functional specification studio** with business problem, user story, rules, acceptance criteria, inputs, dependencies and UAT evidence.
- Added an animated **workflow automation studio**: trigger → API enrichment → deterministic rules → human gate → write-back → telemetry.
- Added an **engineering delivery board** showing Ready / Build / UAT / Release and the business-process engineer role in sprint delivery.
- Added an **adoption & governance control tower** with training, usage, support-feedback loop, RBAC, SaaS licensing and documentation.
- Added a complete generic **commerce operations reference architecture** covering channels, catalog/PIM, pricing, OMS, inventory, seller ops, payments, fulfilment, returns, low-code operations UI, workflow orchestration, APIs/events, data/AI and control-plane services.
- Added an end-to-end **nine-responsibility coverage map**: diagnosis, analysis, scoping, low-code apps, automation, tech-team animation, change, governance and support.
- Kept the website **company-neutral** outside the factual CMA CGM / Volvo / Microsoft experience sections. No Decathlon naming or branding is used.
- Added explicit wording that the new commerce operations lab is a **reference simulation**, not a claim of delivery for a particular retailer.
- Updated cache-busting to `?v=16`.

## Deploy to GitHub Pages
Replace the root files in your repository with:
- `index.html`
- `styles.css`
- `projects.js`
- `script.js`
- `README.md`

Commit to `main`. GitHub Pages should redeploy automatically.
