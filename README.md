# Chintan Changole — Interactive Architecture Portfolio v4

This version upgrades the case studies from simple flow diagrams to enterprise-style application architecture.

## New interaction model
Every project opens into four views:
1. BEFORE — original operating process and friction
2. APPLICATION ARCHITECTURE — full layered platform
3. AFTER — target operating model
4. MY CONTRIBUTION & IMPACT

## Architecture experience
- Four architectural layers
- Monitoring / automation control plane
- Infrastructure, security and governance foundation
- Explicit human, AI, data, control and output components
- Animated flow tracks
- "Play walkthrough" mode
- Automatic component-by-component highlighting
- Live explanation panel
- Every architecture component can be clicked for an explanation

## Accuracy
CV-supported claims are used. The site does not add specific vendor products where the CV does not establish them.
The Volvo architecture therefore uses solution-level component labels rather than asserting an Azure production stack.
The exact CV figure "800 users" is used rather than "800+".

The site says:
Google Cloud — Business Process Engineer & Digital Consultant
Deployed at CMA CGM HQ, Marseille, within the Google × CMA CGM Strategic Partnership.

This is the strongest wording supported by the CV without implying that Chintan personally owns a Google Cloud Partner-status company.
